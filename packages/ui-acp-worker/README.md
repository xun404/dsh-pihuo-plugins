# @pihuo/dsh-pihuo-acp-ui

Web UI half of PiHuo ACP workers: settings section, session team header, and the `acp_worker` tool card.

Install the bundle, not this package alone:

```sh
dsh plugin --profile web add @pihuo/dsh-pihuo
```

`exports["./client"]` is the `__ModuleLoader__` CJS factory at `lib/client.js`.

Source: [xun404/dsh-pihuo-plugins](https://github.com/xun404/dsh-pihuo-plugins).
